# Customer Service Chatbot

This folder contains screenshots of the customer service chatbot implemented on the Allforliz website.

The chatbot provides an additional communication channel for website visitors and helps potential customers begin contact with the company.

## Objective

The main objectives of the chatbot are:

- Improve customer accessibility
- Provide an additional contact option
- Support visitors outside regular business hours
- Help users find service information
- Encourage estimate requests
- Support lead generation

## Main Functions

The chatbot helps visitors:

- Ask initial questions
- Learn about available services
- Contact the company
- Request additional information
- Begin the estimate request process
- Navigate to relevant website sections

## Website Integration

The chatbot is embedded into the website and available across multiple pages.

It appears as a floating contact button, allowing visitors to begin a conversation without leaving the current page.

## Internal Integration

The chatbot is connected to the company's internal workflow and supports the organization of incoming customer inquiries.

Its integration helps direct customer information into the lead management process.

## User Experience

The chatbot implementation was designed to provide:

- Easy access
- Simple interaction
- Consistent availability
- Mobile and desktop compatibility
- Clear communication options
- Integration with the website layout

## Current Status

The chatbot is active on the Allforliz website and connected to the company's internal lead management workflow.
