# Website Screenshots

This folder contains public screenshots related to the Allforliz website optimization project.

The screenshots may include:

- Homepage
- Service pages
- Blog pages
- Contact sections
- Get Your Free Estimate form
- Work With Us form
- Customer service chatbot
- Mobile website layout
- Search engine indexing evidence

## Organization

The screenshots will be organized into folders such as:

```text
assets/screenshots/
├── homepage/
├── service-pages/
├── blog/
├── forms/
├── chatbot/
└── integrations/
```

## Privacy

Before uploading a screenshot, all private or confidential information must be removed or hidden.

The repository will not include:

- Customer names
- Customer phone numbers
- Customer email addresses
- Private form submissions
- Webhook URLs
- API keys
- Access tokens
- Internal database identifiers
