# Allforliz Website Optimization

Technical case study of website performance optimization, local SEO, content architecture and system integrations for Allforliz Painting and Renovations.

## About the Project

This repository documents the work performed to improve and expand the existing Allforliz website.

The original website was not developed by me. My role was to optimize, restructure and maintain the website, focusing on performance, search visibility, user experience and integration with the company's internal systems.

## Main Activities

- Website performance optimization
- Image optimization and replacement
- Creation of service pages
- Local SEO implementation
- Blog creation and publication
- Page indexing
- Internal link organization
- Elfsight form integration
- n8n workflow integration
- Get Your Free Estimate form creation
- Work With Us form creation
- Customer service chatbot implementation

## Tools and Technologies

- Google PageSpeed Insights
- Google Search Console
- Google Business Profile
- Elfsight
- n8n
- Webhooks
- SEO tools
- Image optimization tools
- Website content management platform
