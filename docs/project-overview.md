# Project Overview

## Company Context

Allforliz Painting and Renovations is a residential painting and remodeling company serving Clermont, Orlando and surrounding areas in Central Florida.

The company website is used to present services, publish educational content, attract local customers and collect project requests.

## My Role

The original website was not developed by me.

My role was to manage, restructure and optimize the existing website, focusing on:

- Website performance
- Content organization
- User experience
- Local SEO
- Service page creation
- Blog publishing
- Search engine indexing
- Lead generation
- Third-party integrations
- Workflow automation

## Initial Situation

The website already existed, but required improvements in performance, content structure, service presentation and integration with the company's operational processes.

The main challenges included:

- Large and unoptimized images
- Limited service-specific content
- Need for stronger local SEO
- Need for better page organization
- Manual handling of website submissions
- Lack of integrated lead collection workflows

## Project Objectives

The objectives of the project were:

- Improve loading performance
- Organize the website structure
- Create dedicated pages for each main service
- Improve local search visibility
- Publish relevant blog content
- Index pages correctly
- Create forms for customers and workers
- Connect website submissions to n8n workflows
- Provide an additional customer contact channel through a chatbot

## Main Deliverables

- Optimized website pages
- Optimized images
- Service-specific landing pages
- Blog articles
- Local SEO improvements
- Indexed pages
- Get Your Free Estimate form
- Work With Us form
- Elfsight integrations
- n8n workflow integrations
- Website chatbot

## Project Type

This repository is a technical case study.

It documents the decisions, tools, processes and results related to the optimization and expansion of an existing business website.
